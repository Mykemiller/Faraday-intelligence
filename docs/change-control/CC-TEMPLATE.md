# Change Control template — pointer

The Change Control template is **canonical in one place only**:

`Mykemiller/faraday-jurisdiction-watch` → [`docs/change-control/CC-TEMPLATE.md`](https://github.com/Mykemiller/faraday-jurisdiction-watch/blob/main/docs/change-control/CC-TEMPLATE.md)

Copy it from there for every new Change Control in this repo. Copy the file — never
edit the template in place.

**Do not fork a second full copy of the template into this repo.** A copy drifts, and a
drifted template silently changes what a CC is required to prove — which precheck items
run, where the adversarial review-packet boundary sits, and whether decisions reached
mid-CC get written back to the Faraday Decision Log.

Completed CCs live in this repo, under `docs/` alongside the work they cover.
